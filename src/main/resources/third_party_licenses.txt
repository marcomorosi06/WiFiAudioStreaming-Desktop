5. JAVA RUNTIME
---------------

The app comes with a Java runtime made by jlink/jpackage from Eclipse
Temurin 17.0.20+8 (OpenJDK), with its launcher (libapplauncher). Its licence
is the GNU General Public License, version 2, with the Classpath Exception.
Its own legal notices are in the "legal" folder of the runtime in every
package (lib/runtime/legal on Linux, runtime/legal on Windows,
Contents/runtime/Contents/Home/legal on macOS). Its source code is in the
third-party source archive of each release (section 8), and at
https://github.com/adoptium/temurin17-binaries/releases/tag/jdk-17.0.20%2B8
(OpenJDK17U-jdk-sources_17.0.20_8.tar.gz).

7. PATENTS
----------

Some of the codecs above may be covered by patents in some countries. The
author of this app grants no patent licence beyond the patent grants that
the licences listed here contain (libvpx, libwebp, libaom, SVT-AV1,
Apache-2.0). In particular, Cisco's royalty-free licence for H.264 covers
only the OpenH264 binaries that Cisco distributes, not the OpenH264 compiled
into these FFmpeg libraries.


8. SOURCE CODE
--------------

Each release on https://github.com/marcomorosi06/WiFiAudioStreaming-Desktop/releases
has, next to the packages, the archive
wifi-audio-streaming-<version>-third-party-sources.tar, with:
  - the JavaCPP Presets 1.5.10 build scripts and patch, and the source of
    FFmpeg 6.1.1 and of every library section 2 lists;
  - the source of OpenJDK as built for Eclipse Temurin 17.0.20+8;
  - the source of the AppImage runtime, libfuse 3.15.0 and squashfuse 0.5.2;
  - SOURCES.txt: where every file in it comes from, with its SHA-256.
It stays available for as long as that release is offered. The source of
the app itself is the repository at the tag of the release.
